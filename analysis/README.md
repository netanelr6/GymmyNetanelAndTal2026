# GYMMY Final Project — Reproducible Analysis

This folder contains the code and anonymized processed data used to create the statistical figures in Chapter 5 of the final report.

## Public figure reproduction

The portable script generates **Figures 6–13** from the anonymized CSV files in `data/`.

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
# source .venv/bin/activate

pip install -r requirements.txt
python generate_all_report_figures.py
```

The figures are written to `figures/`:

- Figure 6 — NARS prior attitudes
- Figure 7 — TAP prior attitudes
- Figure 8 — Overall Acceptance: control vs. failure
- Figure 9 — Failure detection by type
- Figure 10 — Failure detection by timing
- Figure 11 — Acceptance change by failure type
- Figure 12 — Acceptance change by failure timing
- Figure 13 — Failure type × timing interaction

## Files

- `generate_all_report_figures.py` — portable public script for Figures 6–13.
- `reproduce_report_results.py` — complete internal reconstruction script used to create the report statistics, appendix tables, and figures from the original workbooks. The raw workbooks are intentionally not included in the public repository.
- `data/clean_analysis_data_public.csv` — anonymized processed session scores.
- `data/pre_questionnaire_scores.csv` — pseudonymous NARS/TAP scores.
- `data/failure_detection_coding_public.csv` — pseudonymous detection/recovery coding without free-text notes.
- `outputs/` — aggregate Appendix E tables and `report_values.json`.
- `figures/` — generated PNG files used in the report.

## Privacy

Do **not** commit the four raw Excel workbooks, videos, consent forms, names, phone numbers, or free-text participant notes. The public CSV files in this folder contain only pseudonymous IDs and variables required to reproduce the published figures.

## Report figures not generated by this script

Figures 1–3 are descriptive images of the exercises, skeletal tracking, and robot hardware. Figures 4–5 are system flowcharts. They are documentation assets rather than statistical figures and are therefore not generated from the experimental dataset.


## Tables and calculations

The full reconstruction script contains the calculations for all numerical findings in Chapter 5: sample summaries, NARS/TAP descriptives, paired t-tests, chi-square tests, recovery rates, change-score descriptives, the two-way ANOVA and diagnostics, and retrospective frequencies.

The `outputs/` folder now includes both Appendix E tables and aliases matching the main-report table numbering. Table 10 is an operational-definition table rather than a computed result. A public, privacy-preserving version of Table F.1 and a standalone Table G.1 mapping are also included. See `outputs/OUTPUTS_MANIFEST.md`.

The raw private workbooks are required to rerun the complete internal reconstruction script from the earliest raw-data stage. They are intentionally excluded from the public repository. The anonymized processed CSV files are sufficient to inspect the participant-level scores and regenerate Figures 6–13.
