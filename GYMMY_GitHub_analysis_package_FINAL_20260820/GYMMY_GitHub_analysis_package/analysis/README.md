# GYMMY Final Project — Reproducible Analysis

This folder contains the code, anonymized processed data, figures, and aggregate output tables supporting Chapter 5 and Appendices E–G of the final report.

## Final terminology used in the report

The final report uses **Acceptance** (not “Overall Acceptance”) and **Failure Recognition** when describing whether a participant noticed the intentionally injected failure. The word *detect* is reserved for system-level detection (for example, the robot detecting abnormal operation).

## Public figure reproduction

The portable script regenerates **Figures 6–13** from the anonymized CSV files in `data/`:

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
# source .venv/bin/activate

pip install -r requirements.txt
python generate_all_report_figures.py
```

Generated files are written to `figures/`:

- Figure 6 — NARS prior attitudes
- Figure 7 — TAP prior attitudes
- Figure 8 — Acceptance: control vs. failure
- Figure 9 — Failure Recognition by failure type
- Figure 10 — Failure Recognition by failure timing
- Figure 11 — Acceptance change by failure type
- Figure 12 — Acceptance change by failure timing
- Figure 13 — Failure type × timing interaction

The numerical values in Figures 8–13 were **not changed** during the terminology update. Only labels/terminology were updated.

## Public data files

- `data/clean_analysis_data_public.csv` — pseudonymous participant-level Acceptance/component scores.
- `data/pre_questionnaire_scores.csv` — pseudonymous NARS/TAP scores.
- `data/failure_recognition_coding_public.csv` — pseudonymous Failure Recognition and recovery coding.

## Appendix and report outputs

The `outputs/` folder contains the aggregate tables supporting the final report, including the newly added:

- `table_E2a_sample_characteristics_by_group.csv`
- `table_E2b_sample_and_prior_attitudes.csv`

It also contains the final Recognition terminology for Tables E.4, E.5, F.1 and the main-report Table 11. See `outputs/OUTPUTS_MANIFEST.md`.

## Verification

Run:

```bash
python verify_public_outputs.py
```

The verification script checks the key numerical values used in Chapter 5, including Acceptance means, Failure Recognition counts, change-score means, and ANOVA statistics.

## Complete raw-data reconstruction

`reproduce_report_results.py` is the full internal reconstruction script used with the four private raw workbooks and the final manual recognition-coding CSV. The raw workbooks are intentionally excluded from the public repository because they contain participant information.

## Privacy

Do **not** commit raw questionnaires, videos, consent forms, names, phone numbers, or free-text participant notes. The public files in this folder contain pseudonymous or aggregate information required to inspect the reported analyses.

Figures 1–5 are documentation/system figures rather than statistical outputs and are therefore not generated by this analysis package.
